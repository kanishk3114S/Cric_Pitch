# Raw Scripts Ingestion Directory

Place your 5 benchmark scripts here.

### Supported formats:
1. `.txt` (Plain text with paragraph breaks and `[pause]` markers preserved) - **Recommended & Fastest**
2. `.docx` (Word documents)
3. `.pdf` (Exported Google Docs PDF)

### Naming Convention:
Name your 5 files matching `backend/data/manifest.json`:
- `SCR-001.txt` (or `.pdf` / `.docx`)
- `SCR-002.txt`
- `SCR-003.txt`
- `SCR-004.txt`
- `SCR-005.txt`
